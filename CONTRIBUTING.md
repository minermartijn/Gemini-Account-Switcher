# Contributing to Gemini Account Switcher

First off, thanks for taking the time to contribute! 🎉

## How to Contribute

1.  **Fork the repository** on GitHub.
2.  **Clone your fork** locally:
    ```bash
    git clone https://github.com/YOUR_USERNAME/Gemini-Account-Switcher.git
    cd Gemini-Account-Switcher
    ```
3.  **Install dependencies** in editable mode:
    ```bash
    pip install -e .
    ```
4.  **Create a branch** for your feature or bugfix:
    ```bash
    git checkout -b feature/amazing-feature
    ```
5.  **Make your changes**.
6.  **Run tests** (if available) to ensure nothing broke.
7.  **Commit your changes** with descriptive messages.
8.  **Push to your fork** and submit a **Pull Request**.

## Reporting Bugs

If you find a bug, please open an issue on GitHub describing:
- What you did (steps to reproduce).
- What happened (the error or unexpected behavior).
- What you expected to happen.
- Your OS and Python version.

## Code Style

- We follow **PEP 8** guidelines for Python code.
- We use **Type Hints** where possible.
- Please run `black .` if you have it installed to format your code before committing.
