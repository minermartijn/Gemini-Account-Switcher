# Code of Conduct Needed

## Issue
There is no `CODE_OF_CONDUCT.md` file in the project. This means there are no explicit community standards or guidelines for behavior, which can be important for open source projects.

## Recommendation
- Add a `CODE_OF_CONDUCT.md` file at the project root.
- Use a standard template (e.g., Contributor Covenant: https://www.contributor-covenant.org/).
- Reference the code of conduct in the `README.md` or `CONTRIBUTING.md`.

## Benefits
- Sets clear expectations for community behavior.
- Helps foster a welcoming and inclusive environment.
- Provides a process for reporting unacceptable behavior.
