# Changelog Needed

## Issue
There is no `CHANGELOG.md` file in the project. This makes it difficult for users and contributors to track what has changed between releases or versions.

## Recommendation
- Add a `CHANGELOG.md` file at the project root.
- Follow a standard format (e.g., Keep a Changelog: https://keepachangelog.com/).
- Update the changelog with every new feature, bugfix, or breaking change.

## Benefits
- Improves project transparency and communication.
- Makes it easier for users to upgrade and understand new features or fixes.
- Helps maintainers keep track of project history.
