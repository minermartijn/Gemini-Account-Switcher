# Contribution Guidelines Needed

## Issue
There is no `CONTRIBUTING.md` file in the project. This can make it unclear for new contributors how to propose changes, report issues, or follow code style and review processes.

## Recommendation
- Add a `CONTRIBUTING.md` file at the project root.
- Include instructions for setting up the development environment, running the CLI locally, and submitting pull requests.
- Specify code style, commit message conventions, and how to run tests (once added).
- Optionally, add a section on how to report bugs or request features.

## Benefits
- Makes it easier for new contributors to get started.
- Improves code quality and consistency.
- Encourages community involvement and growth.
